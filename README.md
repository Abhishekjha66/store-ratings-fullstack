# Store Ratings Platform

A full-stack web application where users can discover stores, submit ratings, and manage their accounts. Administrators can manage users, stores, and platform activity through a dedicated dashboard.

## Live Demo

**Frontend:** https://store-ratings-fullstack-nine.vercel.app

**Backend API:** https://store-ratings-fullstack.onrender.com

## Tech Stack

- **Frontend:** React.js, Vite, JavaScript
- **Backend:** NestJS, Node.js
- **Database:** PostgreSQL, Neon
- **ORM:** Prisma
- **Authentication:** JWT, Role-Based Access Control
- **Deployment:** Vercel and Render

## Key Features

- User registration and login
- JWT-based authentication
- Role-based access for Admin, Store Owner, and User
- Store creation and management
- Store ratings and reviews
- Admin dashboard and user management
- Rating analytics
